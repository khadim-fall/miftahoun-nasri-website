## À trancher par vous (je n'ai pas modifié)

- **Guediawaye / Guédiawaye** : l'orthographe officielle porte un accent ; le site écrit partout « Guediawaye ».
- **Mouridisme / mouridisme** : j'ai gardé la majuscule de « Mouridisme » (respect) mais mis « mouride(s) » en minuscule quand c'est un adjectif, comme le faisait déjà la majorité du site.
- **Termes wolof** : « Wakhtane et sogné », « Xam Xam », « Dieuwrigne sokhna yi » conservés tels quels ; un visiteur non wolophone ne les comprend pas forcément (une courte explication entre parenthèses peut aider).
- **Horaires** : vendredi 20:30 (Contact) / 21:00 (Activités) ; dimanche 23:30 « Groupes d'étude » / 21:00 « Kourel ». Je n'ai pas deviné lequel est juste.
- **Nom du « Président culturel »** et autres titres : à confirmer avec les intéressés.
